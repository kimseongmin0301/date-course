# 욕설·음란어 목록 출처

`badwords.txt`(30분 제한)·`mask.txt`(** 로 가리기만) 는 아래 공개 목록들을 참고해 **직접 고르고 다듬은 목록**입니다.
원본을 그대로 합치면 한 글자 항목(`가`, `사`, `1`)과 평범한 말(`대출`, `카드`, `수술`)이 섞여
욕이 아닌 문장의 65% 이상이 걸려서, 확실한 말만 남기고 우회 표기(자음만 쓰기, 영문 자판으로 치기)와 예외(`allow.txt`)를 더했습니다.
